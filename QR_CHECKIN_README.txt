# 장소별 QR 체크인 업데이트

이 버전은 사용자가 상태 화면의 `사용 시작` 버튼을 누르는 대신, 예약한 세탁실에 붙어 있는 QR을 스캔해야 사용이 시작되도록 바꾼 버전입니다.

## 핵심 변경점

- QR 코드는 기기별이 아니라 장소별로 1개씩만 발급됩니다.
- `Location.qr_token` 컬럼을 추가하고 기존 SQLite DB에는 자동 마이그레이션으로 컬럼을 생성합니다.
- `/qr-checkin/<location_id>/<qr_token>` 경로를 추가했습니다.
- 사용자가 로그인하지 않은 상태에서 QR을 먼저 스캔하면 로그인 후 다시 체크인 URL로 돌아옵니다.
- 같은 장소에서 세탁기와 건조기가 동시에 호출된 경우에는 체크인할 예약을 선택하는 화면을 보여줍니다.
- 기존 `/start/<res_id>/<access_token>` 경로는 더 이상 사용 시작을 처리하지 않고 QR 체크인이 필요하다는 안내만 표시합니다.
- 관리자 화면 `/admin/qrs`에서 장소별 QR을 출력하고 QR 주소를 재발급할 수 있습니다.

## 적용 방법

1. `app.py`를 기존 파일과 교체합니다.
2. `templates/` 폴더의 파일들을 기존 `templates/` 폴더에 덮어씁니다.
3. QR 이미지 생성을 위해 필요한 패키지를 설치합니다.

```bash
pip install "qrcode[pil]"
```

4. 서버를 재시작합니다.
5. 관리자 로그인 후 `/admin/qrs`에서 장소별 QR을 출력해 각 세탁실에 부착합니다.

## 운영 메모

- 기존에 기기별 QR을 이미 붙여두었다면 새 장소별 QR로 교체해야 합니다.
- QR 주소를 재발급하면 이전 QR은 더 이상 동작하지 않습니다.
- 기존 DB에 남아 있는 기기별 `machine.qr_token` 컬럼은 사용하지 않습니다. SQLite에서 컬럼 삭제가 까다로워 자동 삭제하지 않습니다.
