안내

세탁실 예약은
이렇게 이용하세요.

세탁기와 건조기 현황을 확인하고, 빈 기기가 없으면 자동으로 대기열에 등록됩니다.

이용 순서

1

이름과 휴대폰 번호로 시작

휴대폰 번호는 문자 알림을 받을 번호입니다. 하이픈이나 공백을 넣어도 자동으로 정리되며, 010으로 시작하는 11자리 번호를 사용합니다.
2

세탁실 위치 선택

이용하려는 세탁실을 선택하면 해당 위치의 세탁기와 건조기 현황을 볼 수 있습니다.
3

세탁기 또는 건조기 예약

카드에는 빈 기기 수, 대기 인원, 예상 대기 시간이 표시됩니다. 빈 기기가 있으면 바로 사용 가능 상태가 되고, 없으면 대기열에 등록됩니다.
4

차례가 오면 사용 시작

차례가 오면 문자 알림을 받고 상태 페이지의 사용 시작 버튼이 열립니다. 알림 후 5분 안에 사용 시작을 눌러주세요.
5

사용 종료 또는 자동 완료

세탁기와 건조기는 사용 시작 후 50분이 지나면 자동 완료됩니다. 먼저 끝났다면 직접 사용 종료 버튼을 눌러 다음 사람에게 넘겨주세요.

꼭 알아두세요

5분 안에 시작

호출된 뒤 5분 안에 사용 시작을 누르지 않으면 예약이 자동 취소되고 다음 대기자에게 순번이 넘어갑니다.

50분 자동 완료 기준

세탁기와 건조기는 사용 시작 후 50분이 지나면 자동으로 완료 처리됩니다. 완료 후 다음 대기자가 있으면 자동으로 호출됩니다.

먼저 끝나면 직접 종료

50분이 되기 전에 사용이 끝나면 바로 사용 종료를 눌러주세요. 그러면 다음 대기자에게 더 빨리 순번이 넘어갑니다.

동시 예약 제한

한 사람은 세탁기 1개, 건조기 1개까지 동시에 예약할 수 있습니다. 진행 중인 예약은 내 예약 화면에서 확인할 수 있습니다.

예약 취소

아직 사용 시작 전이라면 상태 페이지에서 예약을 취소할 수 있습니다. 사용 중인 예약은 취소 대신 사용 종료를 눌러야 합니다.

상태 화면 보는 법

대기

아직 차례가 오지 않은 상태

내 순번, 대기 인원, 예상 대기 시간을 확인할 수 있습니다. 차례가 오면 문자와 상태 화면으로 알려줍니다.
호출

지금 사용할 수 있는 상태

사용 시작 버튼이 보이면 실제 기기 앞에서 버튼을 눌러주세요. 5분이 지나면 노쇼로 자동 취소될 수 있습니다.
사용

기기를 사용 중인 상태

세탁기와 건조기는 남은 자동 완료 시간을 확인할 수 있습니다. 먼저 끝났다면 사용 종료 버튼으로 다음 사람에게 넘겨주세요.

자주 묻는 질문

문자를 못 받으면 어떻게 하나요?

상태 페이지에서 지금 바로 사용 가능이라고 표시되면 문자 수신 여부와 관계없이 5분 안에 사용 시작을 눌러야 합니다. 휴대폰 번호를 잘못 입력했다면 로그아웃 후 올바른 번호로 다시 이용해주세요.

예상 대기 시간은 정확한가요?

세탁기와 건조기 모두 50분 자동 완료 기준으로 계산됩니다. 사용자가 먼저 종료하면 실제 대기 시간은 더 짧아질 수 있습니다.

예약한 기기 번호는 어디서 보나요?

기기 번호는 빈 기기가 배정되는 시점에 시스템이 자동으로 정합니다. 화면에서는 세탁실 위치와 기기 종류, 현재 상태를 중심으로 확인하면 됩니다.

이미 예약이 있는데 다시 예약할 수 있나요?

세탁기와 건조기는 각각 1개씩만 동시에 예약할 수 있습니다. 같은 종류를 다시 선택하면 기존 예약 상태 화면으로 이동합니다.

이용 매너

다음 사람을 위해 시간을 지켜주세요 세탁물과 건조물은 완료 후 바로 찾아가고, 먼저 끝나면 사용 종료 버튼을 꼭 눌러주세요. 잘못 남은 예약이나 기기 상태가 있으면 관리자에게 알려주세요.
